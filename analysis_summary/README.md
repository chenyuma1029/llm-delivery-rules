# Numerical results

All declared thresholds and partitions are retained. `summary` contains mean contrasts, signed context counts, and fixed-OOF conditional intervals; `grid_sensitivity` contains full-grid, raw/zero-header, ledger/cap, and serializer/header summaries. `context_results` retains every context, including negative and zero results; `high_loss_contexts` is a labeled subset of it. `split_sensitivity` reports all 20 seeds and all context effects. Split quantiles are descriptive, not population confidence intervals. No task identifiers or response text are present here.
