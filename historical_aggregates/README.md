# Historical aggregate results

These unchanged aggregate tables support the original descriptive comparisons retained in Supplement S3 and S5. `negative_cases.csv` contains the 68 changed-order/stable-best contexts; `topset_change_casebook.csv` contains the 49 changed-best contexts. `ranking_scores.csv` and `selection_regret.csv` give complete-grid scores and directional loss summaries. `cost_tails.csv` distinguishes quantile definitions and denominators; `normalized_existing_grid.csv` uses each method's own capacity scale. `compute_costs.csv` records frozen generation costs; `all_AB_conditions.csv` reports the observed dataset/model/method/group conditions, without filling missing combinations.

These are aggregate tables, not raw traces or evaluator reference files. Numeric bytes are preserved from the prior validated analysis. Author-created aggregates are covered by the repository's CC BY 4.0 scope.
